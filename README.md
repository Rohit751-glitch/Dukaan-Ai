# Chhotu_AI Android Demo

Standalone Android shell for Chhotu_AI demo. Built automatically with GitHub Actions.

Build target: installable `Chhotu_AI.apk` with owner login, native microphone permission, editable BookOS approvals, structured results, and Android print support.

Current demo mode: secure Android bridge to the already-tested laptop Chhotu server via an HTTPS Cloudflare tunnel.
